# 2026-10-30 样式缓存修复

PR #1 合并后，用户截图显示新 HTML 的 `b-*` 布局未生效，旧基础样式仍在生效。线上新 HTML 和新 CSS 可完整读取，CSS 与仓库内容一致；响应包含 `cache-control: max-age=600`，而页面仍引用固定的 `assets/site.css`。据此判断为新页面与旧缓存资源混用；新请求不能直接证明用户浏览器缓存中的字节内容。

修复在构建时从实际 CSS/JS 内容计算 SHA-256 前16位，自动输出 `assets/site.css?v=...` 和 `assets/app.js?v=...`。文件内容不变则 URL 不变，内容更新则生成新 URL。原资源文件名、相对路径、单个 CSS/JS 的约束不变；不依赖当前时间或人工维护版本号。

`npm run verify` 校验每页资源版本必须与本地文件实际内容一致，禁止缺版本、错误版本、额外参数、远程资源或其他脚本。回归覆盖首页、日期页、嵌套地图、归档与深路径 404，以及根域名和项目子路径解析。

本次构建、34项测试、35个 HTML 及1,590个内部资源/链接检查通过；没有改变简报 JSON 或视觉样式。已有缓存的页面可强制刷新一次以获取包含版本号的新 HTML。
