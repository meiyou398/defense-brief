## 额外验证

- **18 项 Node 原生测试通过**，包括 schema、错误引用、非法日期与时间、来源 URL、可信度、投影、IANA 时区、重复战区、转义、404 深路径、归档地点和数字搜索。
- **68 项浏览器检查通过，0 个 JS 错误**。详见[浏览器结果](qa/browser-results.json)。
- `npm run verify` 检查 28 个 HTML、1,387 个内部链接与资源，全部通过；包含唯一 ID、有效锚点、完整正文、SEO、RSS、sitemap 和体积预算。
- 生成输出重复构建后 SHA256 一致；构建在写入页面前先校验全部输入。
- Node 20 下另做 CLI 冒烟：旧 HTML 在隔离目录导入得到 4 战区、14 条、4 条投资视角与 18 个来源链接；地图坐标命令输出 9 个坐标、5 条图外，项目原始数据与附件地图均保持一致。
- 一个本地 CSS 和一个原生 JS；无运行时框架与地图计算库。项目依赖仅 `d3-geo`、`topojson-client`、`world-atlas`。浏览器与 Lighthouse 审计工具安装于仓库外的临时目录。
- JS 原始 **14,963 B**，gzip 约 **4.5KB**；首页 HTML + CSS + JS gzip 合计约 **23KB**，原始合计 **106,699 B**；均低于预算。
- 深层错误地址真实返回 404，资源返回 200，“返回首页”正确落在站点根目录。404 通过 `baseUrl` 派生的 `<base>` 解析相对链接。

## 已确认的规格处理

- 手机保留两条 featured 与投资视角；完整版保留六件事，用全部正文替换数字、地图与 featured。
- 地图默认选中首个有坐标的 highlight，样例为 01；首页列表包含全部条目，桌面显示约六行高的滚动窗口。
- 地图支持 1× / 1.5× / 2× 缩放，回到 1× 复位；首版只显示战区、领域两组筛选。
- 增加 `/subscribe/` 占位与 RSS 入口；缺少摘要的 10-17 采用第一条正文前 120 字。
- 统计单位小字使用黑色，保留橙色大数字，以遵守小字对比度要求。地图使用上线版 110m 底图，沿用设计稿的投影与布局。
- 阅读时长依照 `items[].text` 正文字数计算，10-27 为 1,596 字、向上取整 **4 分钟**；设计稿中的 7 分钟为静态示意值。

## 未完全达到的指标

1. **严格 CLS＝0 尚未达到**：冷加载实测为 **0.003734**。日期及首屏容器在增强前后尺寸已固定，剩余微位移来自 Google Fonts `display=swap` 的内部字形与行内文字变化；保留了文档指定的字体与 swap 策略。该值没有影响 Lighthouse 分数门槛，但不能标记为严格零位移。
2. Lighthouse 仍提示欧洲密集标记的触区重叠。按钮具有 44px 命中框，并用真实指针的最近标记中心判定消除遮挡误选；9 个位置真实触摸均通过，同时可从完整地图列表选择。可访问性实测为 96，达到验收线。
